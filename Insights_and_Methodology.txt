DATA MODEL - STAR SCHEMA
================================================================================
Fact Tables:
- Fact_Sales: Combined sales data from 2020, 2021, 2022
- Fact_Returns: Returns data

Dimension Tables:
- Dim_Customer: Customer information
- Dim_Date (Dim_Calendar): Date dimension for time analysis
- Dim_Product: Product details with pricing
- Dim_ProductCategory: Product categories
- Dim_ProductSubcategory: Product subcategories
- Dim_Territory: Geographic/territory information

Measures Table:
- Measures: Dedicated table for DAX measures

================================================================================
RELATIONSHIPS
================================================================================
- Dim_Date[Date] → Fact_Sales[OrderDate] (1:*, Both)
- Dim_Date[Date] → Fact_Returns[ReturnDate] (1:*, Both)
- Dim_Product[ProductKey] → Fact_Sales[ProductKey] (1:*, Both)
- Dim_Customer[CustomerKey] → Fact_Sales[CustomerKey] (1:*, Both)
- Dim_Territory[TerritoryKey] → Fact_Sales[TerritoryKey] (1:*, Both)
- Dim_ProductCategory[ProductCategoryKey] → Dim_Product[ProductCategoryKey] (1:*, Both)
- Dim_ProductSubcategory[ProductSubcategoryKey] → Dim_Product[ProductSubcategoryKey] (1:*, Both)

All relationships set to Both cross-filter direction for bidirectional filtering.
Dim_Date marked as Date Table with Date column.

================================================================================
DAX MEASURES
================================================================================

1. Total Sales
   Formula: SUMX(Fact_Sales, Fact_Sales[OrderQuantity] * CALCULATE(MAX(Dim_Product[ProductPrice]), FILTER(Dim_Product, Dim_Product[ProductKey] = EARLIER(Fact_Sales[ProductKey]))))
   Purpose: Total revenue from sales
   Format: Currency

2. Total Cost
   Formula: SUMX(Fact_Sales, Fact_Sales[OrderQuantity] * CALCULATE(MAX(Dim_Product[ProductCost]), FILTER(Dim_Product, Dim_Product[ProductKey] = EARLIER(Fact_Sales[ProductKey]))))
   Purpose: Total cost of goods sold
   Format: Currency

3. Total Profit
   Formula: [Total Sales] - [Total Cost]
   Purpose: Gross profit
   Format: Currency

4. Profit Margin
   Formula: DIVIDE([Total Profit], [Total Sales])
   Purpose: Profitability percentage
   Format: Percentage

5. YoY Sales Growth
   Formula: 
   VAR CurrentYear = YEAR(MAX(Dim_Calendar[Date]))
   VAR CurrentYearSales = [Total Sales]
   VAR PreviousYearSales = CALCULATE([Total Sales], YEAR(Dim_Calendar[Date]) = CurrentYear - 1, ALL(Dim_Calendar))
   RETURN DIVIDE(CurrentYearSales - PreviousYearSales, PreviousYearSales)
   Purpose: Year-over-year sales growth rate
   Format: Percentage
   Note: Uses YEAR() function on Date column for reliable calculation

6. Total Orders
   Formula: DISTINCTCOUNT(Fact_Sales[OrderNumber])
   Purpose: Count of unique orders
   Format: Whole number

7. Return Rate
   Formula: 
   VAR TotalReturns = SUM(Dim_Returns[ReturnQuantity])
   VAR TotalOrders = [Total Orders]
   RETURN DIVIDE(TotalReturns, TotalOrders)
   Purpose: Percentage of items returned
   Format: Percentage

8. Average Order Value
   Formula: DIVIDE([Total Sales], [Total Orders])
   Purpose: Average revenue per order
   Format: Currency

9. AOV Target
   Formula: 950
   Purpose: Target for Average Order Value (based on current performance of ~$850)
   Format: Currency

10. AOV KPI
    Formula: CALCULATE(DIVIDE([Total Sales], [Total Orders]), ALLSELECTED(Dim_Calendar))
    Purpose: AOV measure optimized for KPI visualization with trend axis
    Format: Currency

================================================================================
KEY CHALLENGES & SOLUTIONS
================================================================================

Challenge 1: Total Sales and Total Cost Calculation
Issue: ProductPrice and ProductCost columns exist in Dim_Product, not Fact_Sales
Solution: Used CALCULATE with MAX and FILTER to look up values per row context
Alternative considered: Power Query merge (rejected due to complexity)

Challenge 2: KPI Visual Showing Blank
Issue: Average Order Value measure returned BLANK when used with trend axis
Solution: Created AOV KPI measure with ALLSELECTED(Dim_Calendar) to remove problematic date filter context

Challenge 3: YoY Sales Growth Showing 0%
Issue: SAMEPERIODLASTYEAR and DATEADD functions not working with date table
Solution: Used YEAR() function on Date column with explicit year comparison
Result: Now showing 171.98% growth (accurate based on multi-year data)

Challenge 4: Null Values in Date Table
Solution: Removed null rows from Dim_Date in Power Query before creating relationships
